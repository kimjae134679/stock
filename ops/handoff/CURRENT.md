## 0. 절대 원칙

**시장 자동화는 데이터 JSON만 갱신한다. HTML/JS/CSS/UI를 매시간 자동으로 다시 만들거나 덮어쓰지 않는다.**

UI 변경은 사용자가 명시적으로 요청한 경우에만 `public/reports/latest.html`과 `public/assets/`를 수정한다. 과거에 이 원칙이 지켜지지 않아 다음 문제가 반복됐다.

- Hero 카드 하나만 남고 나머지 섹션이 사라짐
- 상단 메뉴 버튼을 눌러도 무반응
- `접기/펼치기` 버튼이 브라우저 기본 흰색 네모 버튼으로 깨짐
- 대표주/종목 버튼이 서로 겹침
- 차트가 모바일에서 지나치게 작아짐
- 정상 화면이 잠깐 보였다가 다시 카드 하나짜리 화면으로 돌아감
- 과거에 있던 기능이 안정화 과정에서 통째로 사라짐

따라서 **문제를 고친다는 이유로 기능을 삭제하거나 렌더러를 통째로 갈아엎지 않는다.** 기존 정상 기능을 보존한 상태에서 원인만 수정한다.

## 2. 데이터 Source of Truth

시장 데이터의 기준은 아래 네 곳이다.

- `public/data/latest.json` — 전체 최신 시장/테마/종목/ETF/평가
- `public/data/live/intraday.json` — 당일 시간별 포인트
- `public/data/live/phase-status.json` — 시장/테마 독립 Phase + 행동 코멘트
- `public/data/archive/YYYY/MM/YYYY-MM-DD.json` — 날짜별 최종 스냅샷

### 데이터 원칙

- 미확인 가격은 절대 추정하지 않는다.
- 미국 정규장이 새로 열리지 않았으면 검증된 직전 종가를 유지한다.
- 같은 날 시간별 별도 JSON/HTML 파일을 계속 만들지 않는다.
- `intraday.json` 한 파일 안에 당일 시간 포인트를 누적한다.
- 날짜가 바뀌면 전날 최종본을 archive로 남긴다.

## 3. 매시간 자동화 계약

자동화 ID: `6a847ce3f5dc81918ccab0a7bafaa8fe`

자동화는 지원 가능한 가장 짧은 주기인 **매시간** 실행한다.

자동화가 해야 할 일:

1. 최신 미국/글로벌 시장 상태 확인
2. `latest.json` 갱신
3. `intraday.json` 당일 포인트 추가
4. `phase-status.json` 독립 Phase 갱신
5. 당일 archive JSON 최신화
6. `updated_at`을 실제 완료 KST로 기록
7. 좌측 상단 표시가 `YYYY.MM.DD H시 업데이트`가 되도록 데이터 제공
8. 주요 경보/Phase 변화가 있을 때만 사용자에게 짧게 알림

자동화가 절대 하면 안 되는 일:

- `latest.html` 재작성
- CSS/JS 수정
- UI 섹션 삭제
- 버전 올리기
- 작동 방식 변경

즉 **시장 데이터 갱신과 UI 개발은 완전히 분리한다.**

## 5. 안정적·꾸준한 우상향 후보 요구사항

이 섹션은 단순 종목 리스트가 아니다.

### 표시 방식

- 별도 섹션명: `📈 안정적·꾸준한 우상향 후보`
- **테마별 묶음** 표시
- **순위별 묶음**도 별도 표시
- 각 후보의 **주봉 실제 그래프를 카드 안에서 바로 표시**
- 각 후보의 **1년 / 2년 / 3년 / 5년 누적 주가수익률** 표시
- 데이터 확인 불가 시 `—`, 임의 추정 금지

### 평가 원칙

단순 최근 1년 상승률 순위가 아니다. 다음을 종합한다.

- 5년+ 장기 가격 추세
- 200DMA 기울기/신고가 구조
- 매출/EPS/FCF 성장
- 최대 낙폭과 회복속도
- ROIC/마진
- 부채/희석
- QQQ/SPY 상대강도
- forward earnings revisions
- 구조적 성장 전망

`1년 +100%`라도 최근 폭등 한 번이면 안정적 우상향과 다르게 평가한다.

## 7. 숨은 테마 요구사항

숨은 테마의 MOD/NVT/VRT/FIX 등 티커도 일반 종목과 동일하게 클릭 가능해야 한다.

클릭하면:

- 넓은 실제 차트
- 현재 상태/사이클 또는 구조성장 평가
- 근거
- 주의점
- `그래서 지금은?` 행동

을 보여준다.

사이클형이 아닌 종목에 억지로 `저점→반등→상승→고점`을 붙이지 않는다. 그런 경우 `구조 성장`, `품질`, `CAPEX 수혜`, `병목 수혜`, `현재 상태 평가` 등 실제 특성에 맞는 평가를 쓴다.

## 8. Phase 판정 기준

시장 전체 Phase 하나를 모든 자산에 강제 적용하지 않는다.

최소 독립 평가 대상:

- 미국 전체시장
- Nasdaq/성장주
- 반도체
- AI 네트워크·광통신
- AI 소프트웨어·클라우드
- AI 전력·데이터센터
- 레버리지
- 주요 테마
- 주요 개별 종목

### 단계

`🔥 극단저점/투매 → 🟢 저점후보 → 🟢 바닥형성/확인 → 🟡 저점에서 상승중 → 🟡 중간상승 → 🟠 고점근처/조정 → 🔴 과열/분배 → 🔴 추세붕괴/급락`

필요하면 `⚪ 횡보/불명확` 사용.

### 의미

- `과열/분배`: 단순 낙폭이 아니라 고점권 상승동력 둔화, 좋은 뉴스에도 부진, 거래량 동반 매도, breadth 악화, 분배 징후
- `추세붕괴/급락`: 핵심 지지/중기 추세 이탈, 충격적 급락, 연속 하락, 상대강도 붕괴
- `극단저점/투매`: 변동성/거래량/breadth/강제청산이 패닉 수준일 때만

단계가 반드시 순서대로 진행한다고 가정하지 않는다.

모든 Phase 카드에는 반드시 **`그래서 지금은?`** 행동을 남긴다. 단순히 `고점`, `바닥확인`, `상승중`만 써놓고 끝내지 않는다.

## 15. 마지막 핵심

이 프로젝트의 우선순위는 다음 순서다.

**1) 정상 화면 유지 → 2) 기존 기능 보존 → 3) 데이터 최신성 → 4) 모바일 UX → 5) 새 기능 추가**

새 기능을 추가하면서 1~4를 깨면 실패다. 특히 `화면이 안 깨지는 대신 기능을 삭제`하는 식의 안정화는 금지한다.
