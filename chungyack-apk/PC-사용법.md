# Windows PC에서 열기

1. `stock` 저장소를 pull합니다.
2. `chungyack-apk` 폴더의 **청약_PC보기.bat**을 더블클릭합니다.
3. 기본 브라우저에서 청약 화면이 열립니다. 서버 창은 사용하는 동안 켜 두세요. 창을 닫으면 서버가 종료됩니다.

Windows 기본 PowerShell 5.1과 .NET Framework만 사용합니다. Python, Node, 관리자 권한은 필요 없습니다. 실행 위치와 관계없이 스크립트 바로 옆 `public`을 제공합니다. 두 실행 파일을 원래 폴더에 함께 두세요.

주소는 `http://127.0.0.1:18764/`입니다. 같은 브라우저와 주소를 사용하면 PC의 저장·추적 기록이 유지됩니다. APK의 기록과는 별도입니다. 로컬 PC에서만 접속할 수 있습니다.

데이터는 마지막으로 pull한 파일 기준입니다. 자동 pull 기능은 없습니다. 새로 pull한 뒤 브라우저를 새로고침하면 새 파일을 읽습니다.

## 실행이 안 될 때

- 오류가 나면 창에 이유가 표시되고 키를 누를 때까지 유지됩니다.
- 포트 사용 중: 먼저 켜 둔 서버 창을 닫고 다시 실행하세요. 이미 실행 중이면 위 주소를 브라우저에서 직접 열어도 됩니다.
- `public\index.html` 누락: 저장소 전체를 pull하고 실행 파일 위치를 확인하세요.
- 브라우저 자동 실행 실패: 창에 표시된 주소를 직접 여세요.
- 회사 보안 정책으로 PowerShell 또는 실행이 차단된 경우 정책 담당자에게 문의하세요. 시스템 실행 정책은 변경하지 않습니다.

필요할 때만 PowerShell에서 다른 포트를 지정할 수 있습니다:

```powershell
.\start-pc.ps1 -Port 18765
```

포트가 바뀌면 브라우저 저장 공간도 달라집니다. 서버만 실행하려면 `-NoBrowser`를 추가하세요.
