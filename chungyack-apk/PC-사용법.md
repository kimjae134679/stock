# Windows PC에서 열기

PC에서도 APK와 동일한 라이브 청약 레이더를 사용합니다.

권장 주소:

`https://kimjae134679.github.io/stock/chungyack/?pc=1`

PC 전용 로컬 사본을 별도로 유지하지 않습니다. 따라서 공고 데이터와 UI 버전은 APK와 같은 GitHub Pages 최신본을 사용합니다.

현재 데스크톱 화면도 모바일과 같은 단일 세로 열 레이아웃으로 맞췄습니다. 넓은 모니터에서도 카드가 2열로 벌어지지 않고 가운데 모바일 폭으로 길게 표시됩니다.

기존 `청약_PC보기.bat`/`start-pc.ps1`을 사용하는 경우 최신 파일에서는 위 라이브 주소를 엽니다. 오래된 로컬 복사본이 `127.0.0.1:18764`와 예전 `public` 폴더를 계속 띄우면 저장소를 한 번 최신으로 pull한 뒤 다시 실행하세요.
